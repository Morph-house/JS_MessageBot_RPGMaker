# JS_MessageBot_RPGMaker

카카오톡 같은 메신저 안에서 RPG를 즐길 수 있도록 만든 **RPG 봇 소스**입니다.
누구나 이 소스를 바탕으로 자신만의 RPG 봇을 만들 수 있도록 **RPG 제작 툴**의 역할도 합니다.

봇은 [Wisp](https://github.com/Morph-house) 메신저봇 환경에서 동작합니다.

---

## 🚨 RPG Maker 데이터 만들기 (Google Sheet)

> **게임 데이터(몬스터, 아이템, 던전 등)는 아래 Google Sheet에서 직접 수정하고, JSON으로 추출해서 사용합니다.**

### 📄 Google Sheet 공유 링크

**https://docs.google.com/spreadsheets/d/111Tni203rthPoNdEU70ixx0IFuWg9RhQu_a0sXO5txk/edit?usp=sharing**

### 사용법

1. 위 링크로 Google Sheet에 들어가서 **구글 로그인**을 합니다.
2. **파일 > 사본 만들기**로 내 드라이브에 복사본을 만듭니다.
3. 복사본에서 수정할 테이블을 **수정 / 추가 / 삭제**합니다.
4. **'작업내용 공유'** 탭에서 **JSON 추출** 버튼을 클릭하면 JSON 추출이 진행됩니다.
5. 노란색 칸(**저장할 폴더 키**)에 **본인의 Google Drive 폴더 키 값**을 입력합니다.
   - 이 값을 넣어야 본인의 Google Drive 해당 폴더로 JSON이 들어갑니다.
   - **폴더 키 찾는 법:** 구글 드라이브에서 저장할 폴더를 연 뒤, 브라우저 주소창의 `https://drive.google.com/drive/folders/` 뒤에 있는 문자열(`?` 앞까지)을 복사합니다.
     - 예: `https://drive.google.com/drive/folders/1AbC...xyz?usp=sharing` → 폴더 키는 `1AbC...xyz`

> ⚠️ **반드시 노란색 칸에 본인의 Google Drive 폴더 키를 입력한 뒤 JSON 추출을 진행하세요.**

## 주요 기능

채팅방에 명령어를 입력하면 캐릭터 생성부터 전투, 경제, 소셜 콘텐츠까지 한 번에 즐길 수 있습니다.

- **캐릭터**: 캐릭터 생성/삭제/조회, 스탯 분배, 스킬 설정, 랜덤 스탯, 가방과 장비 관리
- **전투**: 사냥, 던전 진입과 전투, 공격/회복 스킬 설정, 자동 사냥, 전투 기록 및 로그 설정
- **카드 전투**: 덱 목록 관리 및 카드 배틀
- **경제**: 거래소(물품 등록/구매/거래 취소), 예금/대출 계좌, 주식, 도박
- **생산**: 제조, 연금술, 강화, 장비 분해, 레시피
- **채집과 낚시**: 채광, 벌목, 채집, 낚시 등록/기록/랭킹
- **탐험과 점령**: 탐험(익스플로러), 점령지 점령 및 점령지 전투
- **사회 요소**: 클랜, 파티, 친구(관계), 우편, 용병 고용/이적/전직, 펫과 소환수
- **월드 콘텐츠**: 월드 보스, 마이홈(시설 건축/증축/숙박), 도서관, 출석, 숙제 퀘스트, 이벤트
- **편의 기능**: 가이드(`!가이드`), 튜토리얼(`!튜토`), 단축키, 랭킹 정보, 유저 리스트

> 명령어 전체 목록은 봇 안에서 `!명령어`로 확인할 수 있습니다.

## 시작하기

### 요구 사항

- Wisp 메신저봇 실행 환경
- 데이터 파일을 저장할 기기 저장소 (`sdcard/Kmjbot/` 경로 사용)

### 설치

1. 저장소를 내려받습니다.
   ```bash
   git clone https://github.com/Morph-house/JS_MessageBot_RPGMaker.git
   ```
2. `Source/` 폴더의 스크립트를 Wisp 봇 프로젝트에 넣습니다.
   - 진입점은 `Main.js`이며, `project.json`에 스크립트 로딩 순서가 정의되어 있습니다.
3. `Resource/Kmjbot/` 폴더를 기기의 `sdcard/Kmjbot/`에 복사합니다.
   - 기본 데이터(캐릭터, 클랜, 설정 파일)와 샘플 DB(`DB/`)가 함께 들어 있습니다.
4. 봇을 실행한 뒤 메인 방에서 명령어를 입력해 동작을 확인합니다.

### 기본 명령어

모든 명령어는 접두어 `!`로 시작합니다. 접두어는 `Source/Const.js`의 `CommandPrefix`에서 바꿀 수 있습니다.

| 명령어 | 설명 |
| --- | --- |
| `!캐릭생성` | 게임 내 캐릭터 생성 |
| `!로그인` | 게임 로그인 |
| `!가이드` | 현재 위치, 정보, 가능한 행동 확인 |
| `!튜토` | 내 위치의 튜토리얼 보기 |
| `!명령어` | 전체 명령어 목록 보기 |
| `!약관` | 이용 약관 보기 |

## 구조

```
JS_MessageBot_RPGMaker/
├── Source/            # 봇 JavaScript 소스
│   ├── Main.js        # 메시지 진입점, 명령어 라우팅
│   ├── Const.js       # 설정값(접두어, 딜레이, 파일 경로 등)
│   ├── GameManager.js # 이벤트/우편/임명 등 게임 공통 관리
│   ├── *Manager.js    # 기능별 관리 모듈 (전투, 거래소, 클랜 등)
│   ├── DataBase.js    # 데이터 읽기/쓰기
│   └── project.json   # 스크립트 목록과 로딩 순서
└── Resource/
    └── Kmjbot/
        ├── DB/        # 샘플 DB (몬스터, 아이템, 던전, 레시피 등)
        ├── Charactor/ # 캐릭터 데이터
        ├── Clan/      # 클랜 데이터
        ├── Setting/   # 이벤트, 매칭 테이블 등 설정
        └── Users/     # 유저 목록, 거래소, 우편 등
```

- `database/` 폴더는 로컬 데이터 저장용이므로 저장소에 포함되지 않습니다 (`.gitignore` 제외).

## RPG 봇 만들기

이 소스는 "그대로 플레이하는 봇"이면서 "나만의 RPG를 만드는 틀"입니다.

1. `Resource/Kmjbot/DB/`의 파일을 수정해 몬스터, 아이템, 던전, 레시피, 퀘스트를 바꿉니다.
2. `Source/Const.js`에서 접두어, 전투/저장 딜레이, 메인 방 이름 등 운영 설정을 조정합니다.
3. 새 기능은 `*Manager.js` 형식으로 추가하고, `Main.js`의 명령어 분기에 연결합니다.
4. 추가한 스크립트는 `Source/project.json`의 `order`에 등록합니다.
